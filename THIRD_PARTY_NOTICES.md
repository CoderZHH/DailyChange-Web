# React Bits

ScrollFloat and TiltedCard in `components/react-bits/` are adapted from React Bits by David Haz. Source reviewed on 2026-09-26:

- https://reactbits.dev/text-animations/scroll-float
- https://reactbits.dev/components/tilted-card
- https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md

Changes: support server-rendered text and semantic labels, responsive child content, reduced motion, effect cleanup, and a quieter tilt amplitude. The time ribbon and other page choreography are custom implementations.
